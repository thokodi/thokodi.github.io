## Installation

Installing `repository.thokodi-1.0.1.zip` only adds the repository. It does not change Kodi by itself, so restarting Kodi will show nothing new.

1. Settings > System > Add-ons: enable **Unknown sources**.
2. Add-ons > Install from zip file > select `repository.thokodi-1.0.1.zip`.
3. Add-ons > Install from repository > **thokodi repo** > Video add-ons > **Thokodi** > Install.
4. Open Add-ons > Video add-ons > **Thokodi** and choose the build to install.
